Part 5: Create Jenkinsfile for CI/CD pipeline
This is the most important change in Experiment 6.
In Experiment 5, we used separate build commands for Java. Now we will create a Jenkinsfile containing four stages:
1.	Checkout
2.	Build
3.	Test
4.	Deploy
Step 23. Create Jenkinsfile on GitHub
1.	Open the Jenkins-Web-CICD repository.
2.	Click Add file → Create new file.
3.	Enter the filename:
Jenkinsfile
4. Paste the following code:
pipeline {

    agent any

    stages {

        stage('Checkout') {
            steps {
                echo 'Downloading project from GitHub'
                checkout scm
            }
        }

        stage('Build') {
            steps {
                echo 'Building Web Application'
                sh 'ls -l'
                echo 'Build completed successfully'
            }
        }

        stage('Test') {
            steps {
                echo 'Validating HTML code'
                sh 'tidy -q -e index.html'
                echo 'HTML validation completed'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying website to Apache server'

                sh 'cp index.html style.css script.js /var/deploy/'

                echo 'Website deployed successfully'
            }
        }
    }

    post {
        success {
            echo 'CI/CD Pipeline completed successfully!'
            echo 'Visit http://localhost:8000'
        }

        failure {
            echo 'Pipeline failed! Check console output.'
        }
    }
}
5.	Scroll down.
6.	Commit message:
Added Jenkins CI CD Pipeline
7. Click Commit changes.
